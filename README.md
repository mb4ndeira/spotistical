## App projeto Intro a CIencia de Dados CIN 8000

#### Origem dos dados:  
  
  [Top Spotify Songs in 73 Countries - **Kaggle Datasets**](https://www.kaggle.com/datasets/asaniczka/top-spotify-songs-in-73-countries-daily-updated/data)

#### Organização:  

##### /data contém  
- miniBR30.csv - sample de 30 músicas brasileiras para prototipagem leve  
- minis30.csv - sample de 30 músicas aleatórias para prototipagem  
- raw_data.parquet - dados brutos comprimidos para referência  
- spotify_processed.parquet - dados pré-processados  
  
##### /R contém  
- hello.R - rascunho. irá conter o código das análises
